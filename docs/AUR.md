# AUR packages

Official repos are preferred. Each AUR package below is used only because there is no official
equivalent. They are built into the local `[zorpos]` repo (Phase 2+), never installed from the
AUR at runtime.

| Package | Phase | Why it's needed |
|---|---|---|
| `calamares` | 6 | installer; not in official repos |
| `protonup-qt` | 2 | GUI for installing Proton-GE |
| `protontricks` | 2 | winetricks for Proton prefixes |
| `game-devices-udev` | 2 | udev rules for third-party controllers |
| `xpadneo-dkms` | 2 | Xbox wireless controllers over Bluetooth |
| `gamescope-session-steam-git` | 2 | Steam Big Picture session ("Gamer Hive") |
| `aylurs-gtk-shell` / `astal` | 3 | Hive shell framework; to be confirmed against official repos at Phase 3 |

_Phase 1 uses no AUR packages._
